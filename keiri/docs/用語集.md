# NTV 経理 用語集

`keiri` エージェントが扱う頻出用語の定義。表現を勝手に変えないこと。

## 処理区分

| 用語 | 読み | 定義 | 入力先 / 視覚的目印 |
|---|---|---|---|
| 概算 | がいさん | 予算の見込み計上。請求が来る前に想定金額を仮計上する | 月別「概算」列 (例: S 列) |
| X概 | エックスがい | 概算戻し。前月計上した概算を翌月に取り消す処理 | 「処理」列に `X概` (黄背景+赤文字) |
| 概処 | がいしょ | 概算→実伝処理が完了した状態。月次処理完了サイン | 「処理」列に `概処` (緑背景) |
| 実概 | じつがい | 実績計上中で概算がまだ残っている状態 | 「処理」列に `実概` (黄背景+赤文字) |
| 実伝 | じつでん | 実績伝票処理済み。NTV 独自の表現で AI 事業で多用 | 「処理」列に `実伝` (薄水色) |

## 月次サイクル

```
月初: 前月分 X概 → 当月分の概算計上
月中: 請求書到着の都度、実績列に金額入力 + 「実伝」記入
月末: 概算が実績で打ち消されたか確認 → 「概処」記入
```
