# 月次精算ドラフト生成

引数: `$ARGUMENTS` (例: `2026-04`。省略時は当月)

## 手順

**expense** エージェントに以下を実施させます。

### Step 1: 対象期間の決定
- $ARGUMENTS が指定されていればその月、なければ当月 (YYYY-MM-01 〜 月末)
- 対象期間をユーザーに表示して確認

### Step 2: 領収書の収集
- OneDrive の `Receipts/<対象月>/` 配下のファイルを列挙
- 画像 / PDF から日付・金額・摘要・支払先を抽出
- 抽出結果は `workflows/<対象月>-expense/raw.md` に保存

### Step 3: 分類
- `templates/expense-report.md` の自動分類ルールに従い、各明細を勘定科目に分類
- 分類が曖昧なものは `[要確認]` フラグを付ける

### Step 4: 精算書ドラフト作成
- `templates/expense-report.md` をベースに転記
- 出力先: `workflows/<対象月>-expense/draft.md`
- 添付チェックリストを反映

### Step 5: ユーザーへ提示
- 集計サマリー (区分別金額・件数・合計) を表示
- `[要確認]` 項目を一覧化し、ユーザーに分類確認を依頼
- 修正反映後、最終ドラフトを表示

## 出力フォーマット (サマリー部分)

```
# 月次精算ドラフト: <対象月>

## 集計
| 区分 | 件数 | 金額 (円) |
|------|------|---------|
| 旅費交通費 |  |  |
| 会議費 |  |  |
| ... |  |  |
| **合計** |  |  |

## 要確認 (<件数> 件)
| # | 日付 | 摘要 | 想定区分 | 確認ポイント |
|---|------|------|---------|-----------|

## ドラフト
workflows/<対象月>-expense/draft.md を参照
```

## 注意

- **送信・申請は行わない**: 申請ワークフローへの提出はユーザー承認後に手動 (または別途承認コマンド)
- 領収書の原本は OneDrive 上から削除しない
- インボイス登録番号の有無を必ずチェックし、無ければ `[要確認]` を付与
