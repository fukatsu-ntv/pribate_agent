# 朝のブリーフィング

task-controller を主担当として、以下を順に実施し、最終的に1つの「朝ブリーフ」を統合表示してください。

## 手順

1. **task-controller** に当日のタスク状況を集約させる
   - 期日が今日 / 今週 / 期限超過 のタスクを抽出
   - 各エージェントから引き継いだ未完了タスクの確認
2. **mail** に未読メールを要約させる (上位 10 件 / 重要度順)
3. カレンダー MCP で当日の予定を取得 (会議名・時刻・参加者)
4. 結果を以下のフォーマットで統合表示

## 出力フォーマット

```
# 朝のブリーフィング (YYYY-MM-DD)

## 本日の予定
- 09:00–10:00  ◯◯定例 (出席者: …)
- ...

## 期日タスク
### 今日まで
- [ ] ...
### 今週中
- [ ] ...
### 期限超過 (要対応)
- [ ] ...

## 未読メール ハイライト
| # | 件名 | 送信者 | 重要度 | 要返信 | 一行要約 |
|---|------|--------|--------|--------|----------|

## 推奨アクション (優先順)
1. ...
2. ...
3. ...
```

## 注意

- 個人情報を含む詳細は中間ファイル `workflows/<日付>-brief/` に保存
- 送信や予定変更などの不可逆操作は提案のみ。承認はユーザーから受ける
