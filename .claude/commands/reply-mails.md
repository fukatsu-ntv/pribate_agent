# メール返信支援

mail エージェントを使い、未返信メールへの返信ドラフトを順次作成します。

引数: `$ARGUMENTS` (任意のフィルタ条件。空なら全未返信メール対象)

## 手順

1. **mail** に未返信メール一覧を要約させる (フィルタ: $ARGUMENTS)
2. 優先度順に並べる (重要度 × 期限の近さ × 送信者の役職)
3. 上位から1件ずつ返信ドラフトを作成
   - 過去スレッドを文脈に含める
   - 不明点は `[要確認: …]` と明示
4. 各ドラフトをユーザーに提示し、以下のいずれかの指示を待つ:
   - **承認**: そのまま下書きとして保存 (送信は別途承認)
   - **修正**: 修正指示を反映してドラフト更新
   - **スキップ**: 次のメールへ進む
5. 全件処理後、サマリーを表示

## 出力フォーマット (1件分)

```
─────────────────────────────────
[1/N] 件名: ...
送信者: ...
重要度: 高 / 期限: 今日中

▼ 過去スレッド要約
...

▼ 返信ドラフト
件名: Re: ...
本文:
...

▼ 操作
承認 / 修正(指示) / スキップ
─────────────────────────────────
```

## 注意

- **送信はしない**: ドラフトの保存先は Outlook の下書きフォルダのみ
- 機密内容は `workflows/<日付>-replies/` 以下に保存し、最終的に外部共有しない
