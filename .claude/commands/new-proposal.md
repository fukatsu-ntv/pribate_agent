# 新規企画書ドラフト生成

引数: `$ARGUMENTS` (企画のテーマ。例: "シニア向け資産運用アプリ")

複数のサブエージェントを順次連携させ、企画書ドラフトを完成させます。

## 手順

中間成果物は `workflows/<日付>-$ARGUMENTS/` 配下に保存し、ファイルパスで次工程へ受け渡します。

### Step 1: 市場リサーチ
**market-research** に以下を依頼:
- テーマ "$ARGUMENTS" に関する市場規模・トレンド・競合の調査
- 一次情報優先で、出典 URL と取得日を併記
- 出力先: `workflows/<日付>-$ARGUMENTS/01-research.md`

### Step 2: アイデア発散・収束
**brainstorm** に以下を依頼:
- 入力: `01-research.md` をコンテキストとして読み込み
- SCAMPER / クレイジー8 等で発散
- 評価軸 (実現性 × インパクト × 自社適合性) でマトリクス化
- 上位 3〜5 案に収束
- 出力先: `workflows/<日付>-$ARGUMENTS/02-ideas.md`

### Step 3: 企画書ドラフト
**plan-doc** に以下を依頼:
- 入力: `01-research.md` と `02-ideas.md`
- 上位案から1つ (またはユーザー指定の1つ) を選び `templates/proposal.md` に沿ってドラフト作成
- 出典は research の参照番号を保持
- 出力先: `workflows/<日付>-$ARGUMENTS/03-proposal.md`

### Step 4: 統合提示
3 つの中間ファイルへのリンクと、proposal の要点 (エグゼクティブサマリー部分) をユーザーに提示。

## 出力フォーマット

```
# 企画書ドラフト完成: $ARGUMENTS

## 中間成果物
- 01-research.md: 市場・競合調査
- 02-ideas.md: アイデア候補マトリクス
- 03-proposal.md: 企画書ドラフト

## サマリー
（03-proposal.md のエグゼクティブサマリーを抜粋）

## 次のアクション
- [ ] 上長レビュー依頼
- [ ] 関係部門ヒアリング
- [ ] 数値の精査 (予算・KPI)
```

## 注意

- 各 Step の途中で大きな前提が崩れた場合 (例: 市場が縮小傾向で企画前提が成立しない) は、ユーザーに方針確認してから先に進む
- 機密情報を含む場合は中間ファイルを `workflows/` に置き、外部共有しない
